# Clean Campus, Green Campus – Campus Ambassador Registration

## Description

A static Bangla registration page for **Scrap Venture's** "ক্লিন ক্যাম্পাস, গ্রিন ক্যাম্পাস" Campus Ambassador Program. Students from Class 5 to Class 10 can fill in their name, student ID, class, school name and photo. The form validates every field and shows a success message.

This is a frontend-only project. No data is sent to a server or saved to a database.

## Technologies

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Tailwind CSS (CDN)
- Hind Siliguri (Google Fonts)

## Run Locally

1. Download or clone the project folder.
2. Open `index.html` in any modern browser (double-click it).

An internet connection is needed for Tailwind CSS and Google Fonts, which load from a CDN.

## GitHub Pages Deployment

1. Create a new repository on GitHub and upload all project files (`index.html`, `css/`, `js/`, `assets/`, `README.md`).
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and the `/ (root)` folder, then click **Save**.
5. After a minute, your site will be live at `https://<your-username>.github.io/<repository-name>/`.

All file paths are relative, so the site works on GitHub Pages without changes.
